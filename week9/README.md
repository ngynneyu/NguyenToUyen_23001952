# Bài thực hành 9 · Upload ảnh và phân trang sản phẩm

1. Bật **Apache** và **MySQL** trong XAMPP.
2. Mở [phpMyAdmin](http://localhost/phpmyadmin/) và nhập file `database.sql` để tạo cơ sở dữ liệu `week9` với 12 sản phẩm mẫu.
3. Mở [Quản lý sản phẩm tuần 9](http://localhost/week9/).

Kết nối mặc định dùng tài khoản `root`, mật khẩu trống và địa chỉ `127.0.0.1:3306`. Nếu cấu hình XAMPP khác, chỉnh thông tin trong `api/common.php`. Apache cần quyền ghi vào thư mục `uploads`.
